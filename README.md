# Pyxis - Sitio Web Profesional

Un sitio web profesional para Pyxis, empresa latinoamericana especializada en inteligencia artificial, ingeniería de datos y transformación digital.

## Características

### Diseño y Estilo
- **Identidad Visual**: Basada en la paleta de colores y tipografía oficial de Pyxis
- **Estilo**: Limpio, profesional, moderno y cálido
- **Inspiración**: Thoughtworks, Bain & Company, Globant con identidad propia
- **Responsive**: Optimizado para dispositivos móviles y desktop

### Secciones del Sitio

1. **Inicio** - Hero section con propuesta de valor principal
2. **Taller de Discovery** - Workshop inmersivo de IA en 2 días
3. **Pod Pyxis** - Equipos multidisciplinarios para llevar ideas a producción
4. **Casos Reales** - Historias de éxito de empresas LATAM
5. **Nosotros** - Información sobre el equipo y valores de Pyxis
6. **Contacto** - Formulario y datos de contacto reales

### Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Diseño moderno con variables CSS, Grid, Flexbox y animaciones
- **JavaScript**: Interactividad, navegación suave, formularios y efectos
- **Font Awesome**: Iconografía profesional
- **Google Fonts**: Tipografía Inter para consistencia con la marca

### Funcionalidades

- ✅ Navegación responsiva con menú hamburguesa
- ✅ Scroll suave entre secciones
- ✅ Animaciones de entrada y efectos parallax
- ✅ Formulario de contacto con validación
- ✅ Contadores animados en estadísticas
- ✅ Efectos hover en tarjetas y botones
- ✅ Sistema de notificaciones
- ✅ Optimización de rendimiento

## Instalación y Uso

1. **Clonar o descargar** los archivos del proyecto
2. **Abrir** `index.html` en un navegador web
3. **Para desarrollo local**: Usar un servidor HTTP simple

### Servidor Local (Recomendado)

```bash
# Opción 1: Python
python -m http.server 8000

# Opción 2: Node.js (si tienes npx)
npx serve .

# Opción 3: PHP
php -S localhost:8000
```

Luego visitar: `http://localhost:8000`

## Personalización

### Colores de Marca
Los colores están definidos como variables CSS en `:root`:

```css
--primary-color: #1a237e;    /* Azul principal Pyxis */
--secondary-color: #3f51b5;  /* Azul secundario */
--accent-color: #00bcd4;     /* Cyan de acento */
```

### Tipografía
- **Fuente principal**: Inter (Google Fonts)
- **Fallback**: System fonts (-apple-system, BlinkMacSystemFont, etc.)

### Contenido
Todo el contenido está en español y orientado al mercado latinoamericano, con tono profesional y directo para tomadores de decisión.

## Optimizaciones

- **Performance**: Debounced scroll handlers, lazy loading preparado
- **SEO**: Meta tags, estructura semántica, alt texts
- **Accesibilidad**: Navegación por teclado, contraste adecuado
- **Mobile First**: Diseño responsivo desde móvil hacia desktop
